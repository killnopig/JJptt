# 設定檔：匯入與匯出

← [回 JJptt 首頁](../README.md)

JJptt 的擴充功能版、網頁版和 Android App 用同一種設定檔（`jjptt-settings-日期.json`）。三邊都可以匯出，也都可以匯入別邊的檔案：換電腦、換手機、把電腦上調好的 FACT 規則和黑名單搬到手機，都靠它。

## 在哪裡匯出、匯入

| | 匯出 | 匯入 |
|---|---|---|
| **擴充功能版、網頁版** | 右鍵 → 設定 →「同步、備份與更新」→「備份成檔案」→ 匯出設定檔 | 同一個地方 → 從檔案匯入… |
| **Android App** | 設定 → 一般 →「同步」→ 匯出設定檔（從分享選單存到雲端硬碟、傳 LINE、存成檔案） | 同一個地方 → 選擇設定檔匯入 |

擴充功能版另外可以「連結 Google 帳號」自動同步，同步的內容和設定檔完全一樣。

## 會帶過去的

| 類別 | 內容 |
|---|---|
| **FACT** | 每條偵測規則的開關和門檻（秒推、脈衝、補血、門檻推文、罐頭、同網段、機房、同 IP、連推、共伴、首殺班底、門檻班底…）、FACT 報告的設定（幾則推文以上才出現、預設收合）、AI 服務、自訂 AI 網址和提示詞 |
| **名單** | 黑名單、觀察名單、自訂名單和它的名稱、帳號備註、標題關鍵字黑名單、黑名單的人怎麼顯示（淡化／隱藏／不管） |
| **自動黑名單** | 目前名單上的人，連同原因、網址、哪一篇、剩餘時間；被你手動移除、24 小時內不再自動加回的紀錄 |
| **閱讀** | 閱讀模式、連續推文排在一起、重複推文的人變色、隱藏置底文、圖片預載、樓層與國家顯示方式 |
| **搜尋** | 快速搜尋清單、推文數篩選的預設值 |
| **終端機** | 字型、滑鼠操作、防閒置等。App 用不到這些，匯入後也不會影響 App |

## 不會帶過去的

| 內容 | 為什麼、要怎麼搬 |
|---|---|
| **PTT 帳號密碼** | 永遠不會放進設定檔。App 的密碼存在 Android Keystore，只留在那支手機 |
| **跨文章紀錄**（共伴、首殺班底、門檻班底用的） | 這是讀文章時一點一點累積在裝置上的，換裝置要重新累積 |
| **App 的版面**（字級、行距、推文樣式、存起來的版面） | 用「設定碼」分享：設定 → 版面 →「複製碼」，在另一支手機按「貼上碼」 |
| **App 的最愛看板** | 首頁看板列的「同步」按鈕，會從 PTT 帳號的「我的最愛」抓回來 |
| **App 的草稿、發文分類、首頁分頁** | 只留在那支手機 |

## 匯入時會發生什麼

- **會先問你**：匯入前會跳出確認，按確定才套用。
- **是取代，不是合併**：檔案裡有的設定，會蓋掉目前的值。**名單也是整份取代**：手機上原本有、檔案裡沒有的黑名單帳號會不見。想保留兩邊的名單，先在名單比較多的那一邊整理好，再匯出。
- **檔案裡沒有的設定不動**：舊版匯出的檔案沒有新規則的設定，匯入後新規則維持你目前的值。
- **看不懂的設定略過**：比較新的版本匯出、多出來的設定，舊版會直接略過，不會出錯。
- **不是 JJptt 的檔案不會套用**：選錯檔案只會跳出提示，設定不會被改。

## 安全提醒

設定檔裡沒有密碼，但有你的名單和備註。傳給別人前想一下，裡面的觀察名單和備註，你願不願意讓對方看到。

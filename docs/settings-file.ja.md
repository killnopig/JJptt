# 設定を別の端末へ：パソコン ↔ スマホ、機種変更

[中文](settings-file.md) | [English](settings-file.en.md) | **日本語**

← [JJptt のトップへ](../README.ja.md)

パソコンで設定したブラックリストや FACT のルールは、1つのファイルに保存してスマホで開けば、ひとつずつ設定し直す必要はありません。機種変更やパソコンの買い替えでも同じです。（JJptt の画面は繁体字中国語です。ボタン名は画面の表示どおりに書き、かっこ内に訳を付けています）

## どこからどこへ移せる？

すべて移せます。どちらで保存したファイルも同じ形式なので、反対側で開けます。

| 移す元 | 移す先 | できる？ | よくある場面 |
|---|---|---|---|
| パソコンの Chrome 拡張機能版 | Android アプリ | ✅ できる | パソコンで設定したブラックリストや FACT ルールを、スマホでも同じにしたい |
| Android アプリ | パソコンの Chrome 拡張機能版 | ✅ できる | スマホでブラックリストにたくさん追加したので、パソコンも同じにしたい |
| Chrome 拡張機能版 | 別のパソコンの Chrome 拡張機能版 | ✅ できる | パソコンの買い替え、家と職場の2台 |
| Android アプリ | 別のスマホの Android アプリ | ✅ できる | 機種変更 |
| ウェブ版 | 上のどれにでも | ✅ できる | ウェブ版の設定ページは拡張機能版と同じで、使い方も同じ |

## 自分でバックアップできる？

できます。同じ「匯出設定檔」（設定を書き出し）ボタンでファイルを保存し、Google ドライブに置くか LINE で自分に送れば、それがバックアップです。

あとでパソコンを再インストールしたとき、スマホが壊れたとき、設定をうっかり変えてしまったときは、同じ場所で「從檔案匯入…」（ファイルから読み込み、スマホでは「選擇設定檔匯入」）を押してそのファイルを選べば、保存したときの状態に戻ります。

**バックアップに入っているもの**（元に戻すと戻ってきます）：

- ブラックリスト、ウォッチリスト、自作リスト、アカウントに付けたメモ
- 見たくないタイトルのキーワード
- 自動でブラックリストに入った人と、解除までの残り時間
- FACT の各ルールのオン／オフと、自分で変えた数字
- 記事の読み方の設定（同じ人のプッシュをまとめる、固定記事を隠す、国を表示する、など）
- AI 分析で選んだサービスと、自分で書いたプロンプト
- 保存したクイック検索

**バックアップに入っていないもの**（別に対応が必要）：

- **PTT の ID とパスワード**：もう一度ログインするだけです。
- **スマホのレイアウト**（文字の大きさ、行間、プッシュの見た目）：「複製碼」（コードをコピー）を押してメモ帳に保存し、戻すときは「貼上碼」（コードを貼り付け）。
- **スマホのホーム画面の看板（掲示板）**：ログイン後、ホーム画面の「同步」（同期）を押すと、PTT の「我的最愛」（お気に入り）から取り込みます。
- **「共伴」「首殺班底」「門檻班底」の記録**：しばらく記事を読むとまた出てきます。
- **まだ送っていない下書き**。

おすすめ：
- **まとめて設定を変えたあとに1つ保存**：ブラックリストにたくさん追加した、FACT ルールをたくさん変えた、など。
- **ファイル名に日付が入ります**（例：`jjptt-settings-20261113.json`）。最新の1〜2個を残せば十分です。
- **スマホのレイアウトは別に保存**：バックアップに入らないので、「複製碼」でコードも保存しておきましょう。

## 移し方（3ステップ）

1. **元の端末でファイルに保存**
   - パソコン（Chrome 拡張機能版・ウェブ版）：画面を右クリック → 設定 →「同步、備份與更新」（同期・バックアップ・更新）→「匯出設定檔」（設定を書き出し）を押します。
   - Android アプリ：設定 → 一般 →「同步」（同期）→「匯出設定檔」を押し、保存先を選びます（Google ドライブ、LINE で自分に送る、など）。
2. **ファイルを新しい端末へ**：LINE で自分に送る、Google ドライブに置く、自分にメールする、どれでもかまいません。ファイル名は `jjptt-settings-20261113.json` のような形です。
3. **新しい端末でファイルを開く**
   - パソコン：同じ場所で「從檔案匯入…」（ファイルから読み込み）を押し、そのファイルを選びます。
   - Android アプリ：同じ場所で「選擇設定檔匯入」（設定ファイルを選んで読み込み）を押し、そのファイルを選びます。

Chrome 拡張機能版は「連結 Google 帳號」（Google アカウントを連携）もできます。連携すると、どのパソコンも自動で同じ設定になり、ファイルを送る必要はありません。

## 一緒に移るもの

- **リスト**：ブラックリスト、ウォッチリスト、自作リスト、アカウントのメモ、見たくないタイトルのキーワード。
- **FACT の各ルール**：どれをオンにしてどれをオフにしたか、自分で変えた数字（例：何分以内のプッシュを即プッシュとみなすか）。
- **自動でブラックリストに入った人**：理由と、解除までの残り時間も一緒に。
- **記事の読み方**：同じ人のプッシュをまとめるか、固定記事を隠すか、プッシュの横に国を表示するか、など。
- **AI 分析**：ChatGPT、Claude などどれを選んだかと、自分で書いたプロンプト。
- **検索**：保存したクイック検索。

## 移らないもの：新しい端末でやること

| もの | 移らない理由 | どうする |
|---|---|---|
| **PTT の ID とパスワード** | 安全のため、パスワードはファイルに入れません | 新しい端末で一度ログイン |
| **アプリのレイアウト**（文字の大きさ、行間、プッシュの見た目） | これは「コード」で共有します | 元のスマホ：設定 → 版面（レイアウト）→「複製碼」を押して新しいスマホへ送る。新しいスマホ：同じページで「貼上碼」 |
| **アプリのホーム画面の看板** | このリストはもともと PTT のアカウントに保存されています | ログイン後、ホーム画面の「同步」を押すと PTT の「我的最愛」から取り込みます |
| **「共伴」「首殺班底」「門檻班底」のタグ** | 多くの記事を比べて初めてわかるもので、元の端末で読みながら少しずつ記録したものです | 新しい端末でしばらく記事を読むと、だんだん出てきます |
| **まだ送っていない下書き** | 元のスマホにだけあります | 先に元のスマホで送るか、コピーしておく |

## ファイルを開く前に知っておくこと

- **新しい端末はファイルとまったく同じになります。** たとえば新しいスマホですでに何人かブラックリストに入れていても、その人たちがファイルに入っていなければ、ファイルを開いたあとはブラックリストから外れます。なので、**リストがいちばんそろっている端末で保存**して、ほかの端末へ移しましょう。
- **開く前に確認が出ます**。「確定」（OK）を押すまで何も変わりません。
- **古いファイルも使えます**：あとから JJptt に追加されたルールは古いファイルに入っていないので、今の設定のまま残り、消えません。
- **ファイルを間違えても大丈夫**：JJptt のファイルでなければメッセージが出るだけで、設定は変わりません。
- **友だちに送る前に一度考えて**：パスワードは入っていませんが、ブラックリストやメモは入っていて、友だちが開けば見えます。

# FACT（真.事實查核中心）

[中文](fact.md) | [English](fact.en.md) | **日本語**

← [JJptt のトップへ](../README.ja.md)

**FACT = Facts, Accuracy, Credibility & Truth.** PTT のプッシュ（コメント）欄では、組織的な世論誘導がよく見られます。1分以内に同じような言葉が並ぶ、いくつものアカウントが同じIP帯から来ている、プッシュのIPが海外のデータセンター——PTTの画面では自分で数えきれません。JJptt は各プッシュの横に**証拠**を表示し、荒らすアカウントを自動で薄く表示します。**ルールが見るのは行動だけで、立場は見ません。**

![FACT：Evidence over opinion ——透明・一貫・公平・証拠優先・訂正を恐れない](images/fact.png)

FACT がするのは3つです：

1. **検出**：各プッシュに疑わしい点を表示し、プッシュの上にレポートを出します。
2. **対処**：荒らすアカウントを24時間自動でブラックリストに入れ、薄く表示または非表示にします。
3. **取り消し**：どの記録にも理由があり、誤判定はワンタップで外せます。どのルールもオン／オフやしきい値を自分で設定できます。

Chrome 拡張機能版と Android アプリは同じルールを使います。（JJptt の画面は繁体字中国語です。以下のタグ名は画面に表示されるものです）

## 原則

- **同じものさし**：政治的立場、人物の身分、組織の背景で基準を変えません。ルールが見るのは「いつプッシュしたか、何を書いたか、どのIPからか」という行動だけです。
- **証拠を公開**：どの表示にも理由があります（同じIP、データセンター、即プッシュ…）。レポートを開けば、どのアカウントか、どんな数字かが見られます。
- **検証を受け入れる**：誤判定された人は自動ブラックリストから外せます。どのルールもオン／オフやしきい値を自分で設定でき、ワンタップで記事全体をAIに渡して見直してもらうこともできます。
- **変わるのは自分の画面だけ**：FACT は誰かを通報することはなく、ほかの人が見るPTTも変えません。比較に使う記録はあなたのパソコンやスマホにだけ残ります。

## 1. 検出：プッシュの横に表示

![FACT：プッシュの上にレポート、各プッシュに即プッシュ・同一サブネット・データセンター・定型文などの疑いを表示](images/reader-factcheck.png)

プッシュが一定数（初期設定で10件）以上あると、本文とプッシュの間に1行の **FACT レポート**が出ます。開くと全体が見られます。レポートの **AI 分析** ボタンで、記事とプッシュをまとめて選んだAI（ChatGPT、Claude、Perplexity、Grok、Copilot、または自分で設定したもの）に判定させられます。

かっこ内は初期設定のしきい値で、すべて設定で変更できます。

### 時間：いつプッシュしたか

| タグ | 表示される条件 |
|---|---|
| **秒推**（即プッシュ） | 投稿から数分以内（初期設定2分）にプッシュ。本文が長すぎて読み終わるはずがない場合は「秒推‧沒讀完」（即プッシュ・未読）。投稿者自身の補足は数えません |
| **脈衝**（急増） | 静かだった記事に、1〜2分のうちに急にプッシュが押し寄せる（1波6件以上、前後5分以上静か）。「脈衝1、脈衝2…」と表示。ずっと人気の記事は対象外 |
| **補血**（水増し） | ブーイングが多かったあと、とても短いプッシュだけが長く続く（15件以上連続）。「補血?」と表示 |
| **門檻推文**（しきい値プッシュ） | プッシュ数が10前後——記事一覧にプッシュ数が出て目立ち始める数——でぴたりと止まる：10〜12件がすべて投稿後5分以内、その後2時間以上プッシュなし、最初の10件がどれも5文字以内の短いプッシュ |

### IP：どこからプッシュしたか

| タグ | 表示される条件 |
|---|---|
| **機房**（データセンター） | プッシュのIPがクラウドやVPN業者（AWS、Google Cloud、DigitalOcean、M247など34社）のもの。「機房:業者」と表示。2つ以上のアカウントが同じ業者なら「同機房:業者」とし、レポートの1行目に出します |
| **同網段**（同一サブネット） | 別々のアカウントのIPの前3つが同じ（例：101.12.34.x）。3アカウント以上で表示 |
| **同 IP** | 別々のアカウントが同じIPからプッシュ |
| **與作者同 IP**（投稿者と同じIP） | プッシュした人と記事の投稿者が同じIP |

### 内容：何を書いたか

| タグ | 表示される条件 |
|---|---|
| **罐頭**（定型文） | 別々のアカウントが短時間（10分以内）にほとんど同じことを言う：5アカウント以上、言葉の6割以上が共通、6文字以上が連続して同じ（タイトルや本文の引用、しりとり的な連投は除く）。そのうち2アカウント以上に即プッシュ・急増・水増し・同一サブネット・データセンターのどれかもある場合だけ赤い「罐頭A」、言い方が似ているだけなら灰色の「同梗」（同じネタ） |

### 記事をまたいで：いつも一緒に現れる人

いくつもの記事を見て初めてわかるので、使うほど精度が上がります。記録はあなたの端末にだけ残ります。

| タグ | 表示される条件 |
|---|---|
| **共伴**（共起） | A が出てくる記事で、B がよく（7割以上）A の前後3階以内にいる場合、A のプッシュに「共伴:B」。A が5記事以上に出ていることが条件 |
| **首殺班底**（初動の常連） | 同じ投稿者の記事で、あるアカウントが何度も投稿後2分以内にプッシュ（3記事以上、かつ半分以上） |
| **門檻班底**（しきい値の常連） | 同じアカウントが複数（2つ以上）の「門檻推文」記事で最初の10件に入っている。「門檻班底(N篇)」と表示 |

## 2. 対処：自動ブラックリスト

検出は表示するだけです。次の2つは読むのを直接じゃまするので、JJptt はそのアカウントを**24時間自動でブラックリストに入れます**：

| ルール | 条件 | 期間 |
|---|---|---|
| **連推**（連投） | 1つの記事で同じアカウントが続けてプッシュしすぎる（初期設定10件以上）。「連推N」と表示。ほかの人に割り込まれても、3階以内・2分以内に続けていれば同じ連投とみなします。投稿者が自分の記事で続けて返信するのは対象外 | 24時間 |
| **同じURLの荒らし** | 同じアカウントが24時間以内に、同じURLを3つより多くの記事に貼る | 24時間 |

[公告]（お知らせ）と [測試]（テスト）の記事（Re: の返信を含む）は連投の対象外です。

ブラックリストの人の表示は自分で選べます：**薄く表示**（見えるが薄くなる、初期設定）、**非表示**、**通常どおり表示**（ブラックリストを一時停止、リストは保持）。

自動ルールのほかに、3つのリストを自分で管理できます：

- **ブラックリスト**：読みたくない人。薄く表示または非表示。
- **ウォッチリスト**：まだ判断がつかない人。プッシュの横に表示し、メモも付けられます。
- **自作リスト**：名前は自由（例：「工作員」）。プッシュの横にリスト名を表示。

## 3. 取り消し：誤判定のとき

![設定の FACT：どのルールも個別にオン／オフ、しきい値も自分で入力](images/settings-factcheck.png)

- **すべて記録**：自動ブラックリストには理由、URL、どの記事か、いつ追加されたか、残り時間が表示されます。
- **時間が来れば自動で解除**：24時間たてば自動的に消えます。
- **ワンタップで外す**：誤判定だと思ったら「移除」（削除）。手動で外した人は、24時間はルールで再追加されません。
- **永久にする**：本当に見たくなければ「改成永久」で自分のブラックリストへ。
- **どのルールも調整可能**：ルールごとにオン／オフとしきい値、まとめて切り替えも可能。
- **もう一度AIに聞く**：迷ったらレポートの「AI 分析」で、AIに最初から読んでもらえます。

## 設定の場所

| | 検出ルール・しきい値 | 自動ブラックリスト・各リスト |
|---|---|---|
| **パソコン版** | 右クリック → 設定 →「真.事實查核中心」→ 自動偵測（自動検出） | 同じページ上部の「名單」（リスト） |
| **Android アプリ** | 設定 →「真.事實查核」 | 設定 →「黑名單」→ 自動黑名單 |

拡張機能で書き出した設定ファイルはそのままアプリに読み込め、リストとルールも一緒に移ります（IDとパスワードは含みません）。

## よくある質問

**タグが付いたら工作員ということ？**
いいえ。タグは「この行動があるルールに当てはまる」という意味だけです。即プッシュはたまたまオンラインだっただけかもしれません。FACT は証拠を並べて見せ、判断はあなたに任せます。タグが多く、いくつものルールが同時に当てはまるほど、注意する価値があります。

**自動ブラックリストはなぜ24時間だけ？**
連投や荒らしはたいてい一時的なものです。24時間でまず画面をすっきりさせつつ、一度の誤判定でずっと見えなくなることを避けます。本当に見たくなければ「永久にする」を。

**ほかの人に影響する？**
しません。FACT が変えるのは自分の画面だけで、誰も通報しません。記事がAIに送られるのは、自分で「AI 分析」を押したときだけです。

**しばらく使わないと出ないタグがあるのはなぜ？**
共伴・首殺班底・門檻班底は複数の記事を比べるためです。JJptt は読んでいるうちに記録をためていきます（端末の中だけ）。

# FACT（真.事實查核中心）

[中文](fact.md) | [English](fact.en.md) | **日本語**

← [JJptt のトップへ](../README.ja.md)

**FACT = Facts, Accuracy, Credibility & Truth（事実・正確・信頼・真実）。**

PTT のプッシュ（コメント）欄では、何人かが示し合わせてコメントし、「みんながそう思っている」と見せかけることがあります。これを「世論誘導」といいます。

目で見ても気づきにくいものです。たとえば、1分以内に同じような言葉が並ぶ、いくつものアカウントが同じ場所からつないでいる、コメントした人が海外のデータセンターからつないでいる、など。JJptt はこうした**証拠**を各プッシュの横に表示します。

**ルールが見るのは行動だけで、立場は見ません。**（JJptt の画面は繁体字中国語です。以下のタグ名は画面に表示されるものです）

![FACT：Evidence over opinion ——透明・一貫・公平・証拠優先・訂正を恐れない](images/fact.png)

## はじめに：タグが付いても、工作員とは限りません

タグは「この行動があるルールに当てはまる」という意味だけです。そのアカウントが工作員（雇われたり組織されたりして世論誘導をするアカウント）だという意味ではありません。

たとえば先生が、よく似た宿題を2つ見つけたとします。写したとは限りません。2人で一緒に考えただけかもしれません。でも、もう一度見てみる価値はあります。

FACT も同じです。証拠を並べて見せ、**判断はあなたに任せます**。タグが多く、いくつものルールが同時に当てはまるほど、注意する価値があります。

## FACT がする3つのこと

1. **見つける**：各プッシュの横にあやしい点を表示し、プッシュの上にレポートを出します。
2. **対処する**：荒らすアカウント（同じことを何度も書いて、ほかの人のプッシュを押し流す）は24時間自動でブラックリストに入り、薄く表示または非表示になります。
3. **訂正できる**：どの記録にも理由があります。間違いはワンタップで外せ、どのルールもオフにしたり、数字を自分で変えたりできます。

Chrome 拡張機能版と Android アプリは同じルールを使います。

## 用語集

| 言葉 | 意味 |
|---|---|
| **プッシュ（推文）** | 記事の下のコメント。「推」は賛成、「噓」（ブーイング）は反対、「→」はただのコメント |
| **階（樓層）** | プッシュの順番。1つ目のプッシュが1階、2つ目が2階 |
| **投稿者（原 PO）** | その記事を書いた人 |
| **アカウント** | PTT での名前。1人がいくつものアカウントを持つこともあります |
| **世論誘導（帶風向）** | 何人かがわざと大量にコメントして、ある意見を多数派に見せること |
| **工作員（網軍）** | 雇われたり組織されたりして、世論誘導をするアカウント |
| **IP** | ネットにつながる機器それぞれにある、ネット上の住所のようなもの |
| **サブネット（網段）** | IP の前のほうが同じグループ。同じ通りに並ぶ家のようなもの |
| **データセンター（機房）** | サーバーがたくさん置いてある場所。Amazon や Google のクラウドなど。家やスマホからつなぐふつうの人は使いません |
| **VPN** | 別の場所からつないでいるように見せるサービス。本当の居場所を隠すのによく使われます |
| **荒らし（洗版）** | 同じことを何度も書いて、ほかの人のプッシュを押し流すこと |
| **ブラックリスト** | 読みたくない人。その人のプッシュは薄く表示または非表示 |
| **しきい値（門檻）** | ルールの基準線。「2分以内」「5アカウント以上」など。すべて自分で変えられます |

## 原則

- **同じものさし**：政治的立場、誰か、どの団体かに関係なく、基準は同じです。ルールが見るのは3つだけ：いつプッシュしたか、何を書いたか、どこからつないだか。
- **証拠を公開**：どのタグにも理由があります。レポートを開けば、どのアカウントか、どんな数字かが見られます。
- **検証を受け入れる**：間違ってタグが付いた人は自動ブラックリストから外せます。どのルールもオン／オフや数字を自分で設定でき、ワンタップで AI にもう一度読んでもらうこともできます。
- **変わるのは自分の画面だけ**：FACT は誰かを通報することはなく、ほかの人が見る PTT も変えません。比較に使う記録はあなたのパソコンやスマホにだけ残ります。

## 1. 見つける：プッシュの横に表示

![FACT：プッシュの上にレポート、各プッシュに即プッシュ・同一サブネット・データセンター・定型文などの疑いを表示](images/reader-factcheck.png)

プッシュが一定数（初期設定で10件）以上あると、記事とプッシュの間に1行の **FACT レポート**が出ます。タップすると全体が見られます。レポートの「AI 分析」ボタンで、記事とプッシュをまとめて選んだ AI（ChatGPT、Claude、Perplexity、Grok、Copilot、または自分で設定したもの）に判断してもらえます。

下の数字は初期設定です。設定で変えられます。

### 時間：いつプッシュしたか

| タグ | 意味 | なぜあやしい？ |
|---|---|---|
| **秒推**（即プッシュ） | 記事が投稿されてから2分以内にプッシュ。本文が長すぎて読み終わるはずがない場合は「秒推‧沒讀完」（即プッシュ・未読）。投稿者自身の補足は数えません | 読み終わる前に意見を言うのは、記事が出ることを前もって知っていて、プッシュする約束をしていたのかもしれません |
| **脈衝**（急増） | 静かだった記事に、1〜2分のうちに急にプッシュが押し寄せる（6件以上、前後5分以上静か）。「脈衝1、脈衝2…」と表示。ずっと人気の記事は対象外 | 本当に興味がある人は少しずつ来ます。一度に来て一度に消えるのは、誰かが笛を吹いて集めたように見えます |
| **補血**（水増し） | ブーイングが多かったあと、とても短いプッシュが長く続く（15件以上連続）。「補血?」と表示 | 流れが悪くなったのを見て、誰かが人を呼んで点数を戻そうとしたように見えます |
| **門檻推文**（しきい値プッシュ） | プッシュ数が10前後でぴたりと止まる：10〜12件がすべて投稿後5分以内、その後2時間以上プッシュなし、最初の10件がどれも5文字以内 | PTT の記事一覧は、10前後になって初めてプッシュ数が表示され、目立ちます。ちょうどそこで止まるのは「合格ラインまで水増し」したように見えます |

### どこからつないだか

| タグ | 意味 | なぜあやしい？ |
|---|---|---|
| **機房**（データセンター） | プッシュの IP がクラウドや VPN 業者（Amazon、Google など34社）のもの。「機房:業者」と表示。2つ以上のアカウントが同じ業者なら「同機房:業者」とし、レポートの1行目に出します | ふつうは家やスマホからつなぎます。データセンターからつなぐのは、居場所を隠すためや、1人でたくさんのアカウントを動かすためのことが多いです |
| **同網段**（同一サブネット） | 3つ以上のアカウントの IP の前3つが同じ（例：すべて 101.12.34.x） | 住所がそれだけ近いのは同じ通りに住んでいるようなもの。同じグループかもしれません |
| **同 IP** | 別々のアカウントが同じ IP からプッシュ | 同じ住所。1人がアカウントを切り替えている可能性が高いです（同じ学校や会社のネットワークなだけのこともあります） |
| **與作者同 IP**（投稿者と同じ IP） | プッシュした人と記事の投稿者が同じ IP | 投稿者が別のアカウントに切り替えて、自分の記事をプッシュしたのかもしれません |

### 内容：何を書いたか

| タグ | 意味 | なぜあやしい？ |
|---|---|---|
| **罐頭**（定型文） | 10分以内に、5つ以上のアカウントがほとんど同じことを言う：言葉の6割以上が共通、6文字以上が連続して同じ。タイトルや本文の引用、しりとり的な連投は除きます。そのうち2アカウント以上に即プッシュ・急増・水増し・同一サブネット・データセンターのどれかもある場合だけ赤い「罐頭A」、言い方が似ているだけなら灰色の「同梗」（同じネタ） | みんなが同じ原稿を貼り付けているように見えます。たまたま同じネタを思いつく人もいるので、ほかの証拠がそろって初めて赤くなります |

### 記事をまたいで：いつも一緒に現れる人

いくつもの記事を見て初めてわかるので、使うほど精度が上がります。記録はあなたの端末にだけ残ります。

| タグ | 意味 | なぜあやしい？ |
|---|---|---|
| **共伴**（共起） | A が出てくる記事で、B が7割以上 A の前後3階以内にいる場合、A のプッシュに「共伴:B」。A が5記事以上に出ていることが条件 | 2つのアカウントがいつも前後して現れる、まるでコンビのようです |
| **首殺班底**（初動の常連） | 同じ投稿者の記事で、あるアカウントが何度も投稿後2分以内にプッシュ（3記事以上、かつ半分以上） | いつも一番乗り。その投稿者の前座を決まって務めているように見えます |
| **門檻班底**（しきい値の常連） | 同じアカウントが2つ以上の「門檻推文」記事で最初の10件に入っている。「門檻班底(N篇)」と表示 | 「合格ラインまで水増し」があるたびに、必ずいます |

## 2. 対処する：自動ブラックリスト

上のタグは表示するだけです。次の2つはみんなが読むのを直接じゃまするので、JJptt はそのアカウントを**24時間自動でブラックリストに入れます**：

| ルール | 条件 | 期間 |
|---|---|---|
| **連推**（連投） | 1つの記事で同じアカウントが続けてプッシュしすぎる（初期設定10件以上）。「連推N」と表示。ほかの人に割り込まれても、3階以内・2分以内に続けていれば同じ連投とみなします。投稿者が自分の記事で続けて返信するのは対象外 | 24時間 |
| **同じ URL の荒らし** | 同じアカウントが24時間以内に、同じ URL を3つより多くの記事に貼る | 24時間 |

タイトルが [公告]（お知らせ）や [測試]（テスト）の記事と、それへの返信（Re:）は、連投の対象外です。

ブラックリストの人の表示は自分で選べます：**薄く表示**（見えるが薄くなる、初期設定）、**非表示**、**通常どおり表示**（ブラックリストを一時停止、リストは保持）。

自動ルールのほかに、3つのリストを自分で管理できます：

- **ブラックリスト**：読みたくない人。薄く表示または非表示。
- **ウォッチリスト**：まだ判断がつかない人。プッシュの横に表示し、メモも付けられます。
- **自作リスト**：名前は自由（例：「工作員」）。プッシュの横にリスト名を表示。

## 3. 訂正できる：間違っていたら

![設定の FACT：どのルールも個別にオン／オフ、しきい値も自分で入力](images/settings-factcheck.png)

- **すべて記録**：自動ブラックリストには理由、URL、どの記事か、いつ追加されたか、残り時間が表示されます。
- **時間が来れば自動で解除**：24時間たてば自動的に消えます。
- **ワンタップで外す**：間違いだと思ったら「移除」（削除）。手動で外した人は、24時間はルールで再追加されません。
- **永久にする**：本当に見たくなければ「改成永久」で自分のブラックリストへ。
- **どのルールも調整可能**：ルールごとにオン／オフと数字を設定でき、「全部開啟／全部關閉」（すべてオン／すべてオフ）でまとめて切り替えも。
- **もう一度 AI に聞く**：迷ったらレポートの「AI 分析」で、AI に最初から読んでもらえます。

## 設定の場所

| | 各ルールのオン／オフと数字 | 自動ブラックリスト・各リスト |
|---|---|---|
| **Chrome 拡張機能版** | 画面を右クリック → 設定 →「真.事實查核中心」→ 自動偵測（自動検出） | 同じページ上部の「名單」（リスト） |
| **Android アプリ** | 設定 →「真.事實查核」 | 設定 →「黑名單」→ 自動黑名單 |

パソコンで設定したルールやリストは、ファイルに保存してスマホへ移せます（逆もできます）。設定し直す必要はありません：[設定を別の端末へ](settings-file.ja.md)。

## よくある質問

**自動ブラックリストはなぜ24時間だけ？**
連投や荒らしはたいてい一時的なものです。24時間でまず画面をすっきりさせつつ、一度の間違いでずっと見えなくなることを避けます。本当に見たくなければ「永久にする」を。

**ほかの人に影響する？**
しません。FACT が変えるのは自分の画面だけで、誰も通報しません。記事が AI に送られるのは、自分で「AI 分析」を押したときだけです。

**しばらく使わないと出ないタグがあるのはなぜ？**
共伴・首殺班底・門檻班底は複数の記事を比べるためです。JJptt は読んでいるうちに記録をためていきます（端末の中だけ）。
